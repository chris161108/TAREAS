Este párrafo acompaña a los encabezados para mostrar cómo el texto se adapta proporcionalmente al ancho de la ventana.

Ejemplo de regla

/* ejemplo */
h1 { font-size: clamp(1.5rem, 4vw + 1rem, 4.5rem); }
h2 { font-size: clamp(1.125rem, 2.5vw + 0.6rem, 3rem); }

Redimensiona la ventana para ver el efecto.
